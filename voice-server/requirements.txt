# Pinned deliberately. The previous unpinned list made every rebuild a
# different environment, which is why "did that fix it?" was never answerable.
#
# torch and torchaudio are deliberately ABSENT. The base image
# (runpod/pytorch:2.8.0-py3.11-cuda12.8.1) already ships both, built against
# the CUDA it carries. Pinning torch here doesn't protect that — it forces pip
# to reinstall torch and every nvidia-*-cu12 wheel behind it, ~3GB of download
# to arrive back where we started. The Dockerfile asserts afterwards that
# resolving voxcpm left the image's torch intact, which is the actual risk.

# 2.0.3 (11 May 2026) is the current release and a true VoxCPM2-family build.
voxcpm==2.0.3

# The exact version the VoxCPM FAQ lists as verified. This is the package whose
# rearrange() broke torch.compile tracing, so it is the last one that should be
# floating.
einops==0.8.1

runpod==1.7.7
soundfile==0.12.1
